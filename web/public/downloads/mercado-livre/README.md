# Disparei — Mercado Livre

Ponte Manifest V3 entre a sessão Mercado Livre do próprio usuário e o Piloto Automático. Não lê nem envia cookies, não faz disparos e não automatiza login.

Para desenvolvimento, execute `npm install` e `npm run build`, depois carregue esta pasta em `chrome://extensions` usando **Carregar sem compactação**.
